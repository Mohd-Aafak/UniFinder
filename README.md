# 🎓 UniFinder — University Search App

UniFinder is a web application that helps users explore and search for universities using a simple and responsive interface.

## 🚀 Live Demo
🔗 [View UniFinder Live](https://mohd-aafak.github.io/UniFinder/)

## 💻 Source Code
🔗 [View Source Code on GitHub](https://github.com/Mohd-Aafak/UniFinder)

## ✨ Features
- 🔍 Search universities
- 🌍 Explore universities by country
- 🎯 Filter and sort search results
- ⭐ Save favorite universities
- 📱 Responsive design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- API Integration
- LocalStorage
